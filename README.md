# Coeus

A personal agent that uses a computer like a human, learns like a colleague, and stays small. Research and design only as of 2 September 2026; nothing is built yet.

## Documents

| File | What it is |
|---|---|
| `docs/COEUS_PLAN.md` | The design: architecture, what is new, what we take from other agents, the loop, memory, browser, tools, safety, reliability, build order |
| `docs/HARNESS_V2.md` | The comparison of OpenClaw 2.0, Hermes, Prime, OpenCode, Atomic, ZeroClaw, Codex, and Claude Code, with one diagram each |
| `docs/html/` | The same two documents as rendered pages with the diagrams drawn |
| `docs/research/` | The seventeen study files the documents were written from, with `file:line` citations into the source repositories |

Diagrams are mermaid blocks. In VS Code, open the preview (Cmd+Shift+V) with the "Markdown Preview Mermaid Support" extension, or open the pages in `docs/html/`.

## Rules the design follows

Simple. Linux only. English. Signal or a terminal. The browser, like a human, always, with its own profile. Minimal tokens. Plain short answers. Tests first.
