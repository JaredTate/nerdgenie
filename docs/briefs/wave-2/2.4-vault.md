## The package

## What to build

- **The file.** `~/.nerdgenie/vault.age`, encrypted with `filippo.io/age` (pre-approved) to an X25519 identity whose private key lives in `~/.nerdgenie/vault.key` with mode `0600`, created on first use. Opening refuses a key file whose mode allows group or world access, or whose owner is not the current user, with an error that says the mode to set. The plaintext is a small JSON document of entries; the whole file is rewritten on every change, atomically (write beside, sync, rename).
- **Entries.** Name, site, domains (the hosts the entry may be used on), username, password, and a TOTP secret; plus a `sudo` entry that has only a password. Names are unique. Values are never logged, never printed except through the masked prompt's echo of asterisks, and never returned to any caller but the harness functions below.
- **The masked prompt.** A function that reads a secret from the terminal with echo off, using the standard library's `syscall` termios calls (`TCGETS`/`TCSETS` on the terminal file descriptor), restores the terminal on every path including interrupt, prints one asterisk per character, and refuses to run when standard input is not a terminal. This is the only way a value enters the vault: `/vault add <name>` in the terminal, and `nerdgenie init` in wave 3 uses the same function for the API key.
- **The resolver.** `Resolve("secret://name")` returns the credential struct from `contract` to the harness (the browser login tool of wave 5 and the provider's key lookup in `serve.go`); any other form is an error naming the form. The `web`, `shell`, and every model-facing path never call it; the tool registry of brief 2.5 enforces that by construction, and you enforce it by making the return type one the model-facing code cannot serialize (a struct whose text form is `[secret]`).
- **TOTP.** Six digits, thirty seconds, SHA-1, from the entry's secret, through `github.com/pquerna/otp` (pre-approved), with a function that also returns the seconds left so the login tool can wait for a fresh code when fewer than five remain.
- **Sudo.** `SudoPassword()` returns the `sudo` entry's password to the harness only. The askpass path: a subcommand value in your own file `cmd/nerdgenie/askpass.go`, `nerdgenie askpass`, that opens the vault and prints the sudo password to standard output, exiting with a message when there is none; the shell tool's escalation of brief 2.5 runs `sudo -A` with `SUDO_ASKPASS` pointing at the nerdgenie binary with that argument. Say the subcommand's value name in your report so the orchestrator registers it.
- **Redaction.** `Redact(text)` replaces every vault value that is at least six characters long, and every string that looks like a secret whether or not it is in the vault: Anthropic and OpenAI key shapes (`sk-ant-`, `sk-`, `sk-proj-`), bearer tokens in `Authorization` headers, `password=` and `token=` query values, AWS-style key ids, private key blocks, GitHub tokens (`ghp_`, `gho_`), Slack tokens (`xox`), and a six-digit code on a line that also says code or OTP. The replacement is `[redacted]`. It runs on every message a channel sends, on every log body, and on every tool result, through `contract.Secrets`; those callers are other packages' work, and your job is to make the function fast (compile once, one pass) and safe on any input.
- **`/vault`.** A `contract.Command` value, terminal only: `list` (names and sites, never values), `add <name>` (the masked prompt for each value), `remove <name>`, `test <name>` (prints whether the entry decrypts and, for a TOTP entry, that a code was generated, without printing it). Over any channel but the terminal it answers with one line saying the vault works only in the terminal.

## Tests, in the order you write them

1. Round-trip: add three entries, close, reopen, read them back; the file on disk is not plaintext.
2. Loose key permissions (`0644`, `0660`) refused with the message; `0600` accepted.
3. The resolver: a good reference, a bad form, a missing name; the returned struct prints as `[secret]`.
4. TOTP against the RFC 6238 test vectors for SHA-1 at the known times, and the seconds-left value on a fake clock.
5. Redaction on ten secret shapes, each with a before and after, and a check that ordinary text (an email address, a hash, a version number) is untouched.
6. The masked prompt never echoes: run it against a pseudo-terminal pair opened with the standard library, type a secret, and assert the output has only asterisks; and it refuses a pipe.
7. `/vault` refused over the fake Signal-shaped channel and accepted over the fake terminal-shaped channel; `list` never prints a value.
8. The askpass subcommand prints the sudo password when one exists and a message when not.
9. A fuzz test on the entry file parser: any bytes, no panic, and a bad file is an error that names the file.
