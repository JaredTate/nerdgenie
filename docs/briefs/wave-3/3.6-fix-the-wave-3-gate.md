## What this brief is

Four packages merged for wave 3 were read by a reviewer with fresh eyes before the human trial, and the findings below are in the reviewer's own words, grouped by package. One worker per package fixes only its package's findings, in order: first a failing test that reproduces the problem exactly as the reviewer proved it, then the fix. Every function under sixty lines, every file under five hundred. Rebase onto `main` first; the contract changes named below are on `main` already.

The trial runs on the local Qwen with a person at an eighty-by-twenty-four terminal, so the findings marked BLOCKING are the ones that person would hit in the first minute.

## internal/tui, the terminal screen

1. **BLOCKING. An error card above a pending preview silently steals its single-key answers.** `internal/tui/screen.go:282` `focusedCard` scans backwards and returns nil at the first card block it meets that does not take keys; `screen.go:298` `showTrouble` appends an error card with `answered: true`. With a preview on screen, one `error` envelope (which the socket sends for a bad line, a full queue, or a wrong preview number) makes `a` type the letter into the input box instead of approving, while the card still draws its three answers. Fix: hold the pending card in a field instead of finding it by walking the transcript, and prove with a test that an error card arriving above a preview leaves `a`, `A`, and `r` working.

2. **BLOCKING. The first frame a person sees is 24 columns by 8 rows.** `cmd/nerdgenie/tui.go:38` builds `tui.Options` with no width or height, `screen.go:145` falls back to 24 by 8, and Bubble Tea paints the first view before it delivers the first size message. Fix: read the terminal size in `Run` before the program starts (the standard library's `syscall` `TIOCGWINSZ` on the terminal descriptor, with 80 by 24 as the fallback) and pass it into `New`; test that `Run`'s size reader is used and that the first frame at a fake 100 by 30 is 100 by 30.

3. **HIGH. Three design numbers are unpinned.** `heartbeatInterval` (30 ms), `spinnerRate`, and `widestTranscript` (100) can each be changed without any test failing, because the tests advance by the constant itself. Fix: assert the literal values, as the spinner's 500 ms delay and 3 s hold already are.

4. **HIGH. The header and the status strip glue their right side onto their left between sixty and seventy-two columns.** `geometry.go:81` `padTo` no-ops when the row is already past the target, so the health mark and the key hints are appended with no gap and cut mid-word. Fix: require a minimum gap and drop the right-hand piece entirely when it will not fit, as the design's "degrades by dropping the right side" asks; golden frames at sixty and sixty-eight columns.

5. **MEDIUM.** A handoff screenshot is read off disk and base64-encoded on every heartbeat while its card is on screen (`pictures.go:51`, `card.go:114,127`). Encode once when the card is made. **6. MEDIUM.** A `reply` envelope with `Attachments` (a file sent to the terminal) loses its path (`envelope.go:12`); show it. **7. MINOR.** A dropped link wipes the header to the single word `connecting`; keep the last known model, task, and cost with the state word changed.

## internal/channel, the queue, router, stream, and socket

8. **BLOCKING. Escape at a masked prompt wedges the agent for fifteen minutes.** The screen's cancel sends `deny` with the prompt's id, the socket routes every `deny` to the previews, the prompt is registered elsewhere, and `AskSecret` waits out the whole deadline. `main` now has `contract.SocketCancel`, a screen-to-program type that cancels a preview or a masked prompt by id: route it to whichever is waiting, and have `AskSecret` return an error naming the cancellation at once. The screen worker changes the screen to send it (finding 8b below).

9. **BLOCKING. The reason a person types when rejecting a preview is thrown away.** `client.go:180` calls `answerPreview` without reading `envelope.Reason`, and `ShowPreview` has nowhere to put it. `main` now has `contract.PreviewAnswerWithReason` and `Channel.ShowPreview` returns it (the answer plus the reason); carry the reason through, and the fake channel and the check already expect it.

10. **BLOCKING. Redaction of everything but `Text` is untested.** Deleting the `Title`, `Reason`, and `Fields` lines from `channel.go:168-180` leaves the package green. Extend `TestEverythingSentOutIsRedactedFirst` to a title, a reason, and a field.

11. **HIGH. `Esc` while a task runs sends `/stop`, which nothing registers.** The loop (brief 3.1, being written now) registers `/stop`; until it lands, route an unknown `stop` to the `StartTask` owner's stop function, supplied through `Routes.StopTask func(ctx) error`, and say so in `ARCHITECTURE.md`.

12. **HIGH. Two copies of the terminal channel name and two slash-command splitters with different rules.** `channel.go:22` redefines `TerminalChannelName`; use `contract.TerminalChannelName`. `router.go:165` `SplitCommand` lowercases and splits on any space while `command.Registry.SplitLine` does neither, and `router.go:118` calls `command.Run` directly, so `Registry.Run` and its terminal-only refusal are dead on the real path. Fix: the router calls `Registry.Run` through the `FindCommand`-style function it is given (change the function's shape to `RunCommand func(ctx, line, where) (string, error)`), and delete the router's own splitter.

13. **MEDIUM.** Nothing fills `contract.StatusFieldCommands` and no status is sent on attach or as a heartbeat, so the palette is empty and the health dot goes hollow after ten seconds. Fix in the stream: on every attach send one `status` with the command list (from a function the options supply) and the state, and send a `status` heartbeat every five seconds on the clock.

14. **MINOR.** `DefaultAnswerDeadline` ignores the user's `time_per_turn` unless passed; `shortenedText` splits runes; `Socket.Receive` watchers are uncapped. Fix all three.

## internal/command, the registry, the core commands, `init`, `doctor`, `install`, `uninstall`

15. **BLOCKING. `nerdgenie init` dead-ends the ordinary first-time user.** `initmodels.go:118-126` keeps only detected or key-needing choices, so with nothing detected the menu is two API-key options, Enter aborts, and there is no path through. Fix: print one line above the menu saying what was not found; always offer a last line, "the local model at http://127.0.0.1:19091/v1 (start it later)", which writes the shipped `local` alias with a comment; and make Enter at an empty key prompt go back to the menu instead of aborting.

Say the home folder was made but no configuration was written, and that running `nerdgenie init` again picks up there.

18. **HIGH. The model detection order is untested.** Swapping any two adjacent choices in `initmodels.go:76-113` leaves the tests green. Fix: one test with all four detectors answering, asserting the menu as a golden and that `--yes` picks `local`.

19. **HIGH. No functional test.** Add `test/functional/command_test.go` driving `/help`, `/status`, and `/undo` through the socket from `internal/channel` with the fakes.

20. **MEDIUM. Four bounds are untested:** `--reset-config` overwriting a hand-written `SOUL.md` is not caught, the chmod on a pre-existing home is not asserted, `maxTriesPerQuestion` can change freely, and both timeouts only see a pre-cancelled context. Pin each. **21. ## internal/memory

24. **BLOCKING. Capture drops a long task's later events.** `capture.go:85-88` takes `ByTask`'s first page and treats the cap error as success. Page with `ByRange` until the end, and treat a real read failure as a failure.

MEDIUM.** Bound the rebuild's reads (`forgetMissingNotes` with no limit, whole-file reads before the budget, a full replay on every open, `prepareFacts` with no batch cap) and fix `Get` cutting `MaxNoteBytes` in runes. **28. MINOR.** Fix the contract comment that says "newest first" (orchestrator's file; report the sentence you want), and drop the nine exported constants nothing references.
