## What each one means

**Finding 1, the context measure.** The header draws `costWords` from the session's tokens in and out, and the wiring fills only the model, the task, the state, the health mark and the command list into the status (`cmd/coeus/wiring.go:442`). So the header has nothing to draw. The person wants what opencode's status line shows: how many tokens the last call held, the model's window, and the share, such as `ctx 12.4k / 262k · 5%`. The contract now has `StatusFieldContextTokens` (the input tokens of the last call, which is the context in use) and `StatusFieldContextWindow` (the model's `ContextLength`).

**Finding 2, Escape.** `internal/tui/keys.go:150` `pressedStop` sends the stop command only while a task is running. A plain reply is not a task, so Escape does nothing while the model thinks, and even during a task the stop must reach the model call in flight and cancel it, not wait for the reply to finish.

**Finding 3, the monitor.** While the state is thinking the strip shows a spinner and nothing else. The contract now has `StatusFieldStreamed` (output tokens of the call so far) and `StatusFieldCallStarted` (when it began, RFC 3339). The strip should read `thinking · 14 s · 212 tokens` and tick each heartbeat, so a stuck model is visible in ten seconds instead of a quarter hour.

**Finding 4, the browser worker.** `make build` did not build the worker bundles until brief 6.3's fix landed; it does now, and `bin/workers/browser/main.js` exists on `main`. The serve turns the browser tools on when the bundle is there. Nothing to fix in code; the trial serve was restarted on the new binary.

**Finding 5, tasks and jobs.** `/tasks` lists the tasks, `/tasks 17` shows one, `/jobs` lists the jobs, and the header names the running task. The palette (`/`) lists all of them with one-line help. The screen's first frame should say so under the banner tag: `type / to see the commands`. One line, tested in the golden frame.

## internal/tui, the terminal screen

- **Finding 1.** The header shows the context measure when the status carries `StatusFieldContextTokens` and `StatusFieldContextWindow`: `ctx 12.4k / 262k · 5%`, dim, after the model alias; the share turns warning-coloured at eighty percent and error-coloured at ninety-five. Keep the session tokens and money after it when they are sent. Golden frame with both, and one with neither.
- **Finding 2.** Escape sends `stop` whenever the state is thinking or using a tool, and whenever a task is running, whichever is true. Test each state.
- **Finding 3.** The strip shows `thinking · 14 s · 212 tokens` from `StatusFieldCallStarted` and `StatusFieldStreamed`, counting on the fake clock; test at zero, at fourteen seconds, and after the call ends. The counter must not flicker with the spinner rule.
- **Finding 5.** The banner's tag line says `type / to see the commands`.

## cmd/coeus and internal/loop, the wiring and the turn loop

- **Finding 1 and 3.** After every model call the status carries the session tokens in and out, the money when the provider reports it, the budget line, `StatusFieldContextTokens` from the call's `Usage.InputTokens`, and `StatusFieldContextWindow` from the model's `ContextLength`.
